# Webmail UX research digest — inputs to the Phase 1 design

Researched 2026-09-02 (four parallel tracks: Superhuman, Gmail, ihasmail source, HTMX/Alpine techniques).
Sources are cited inline in the full agent reports; this digest keeps the design-relevant facts.
Values marked ≈ are approximate; UNVERIFIED items are flagged.

## 1. Superhuman — what makes it feel world-class

- **Structure:** three flex panes — collapsible left nav (hidden until `←`), centred thread pane (≈640 px + 8 rem), right contact/calendar pane (260–423 px). List-first: the conversation *replaces* the list ("one thing at a time"); drafts are full-screen with a pop-out escape hatch. No reading-pane option found (UNVERIFIED as official).
- **Split Inbox:** a tab row above the list (Important · Calendar · Docs · Other) with *total* counts, Tab/Shift+Tab to move, tabs auto-hide when empty, ≤7 recommended.
- **Rows:** single line, sender column, medium-weight subject, grey snippet inline, coloured label pills before the subject, purple left edge on the focused row, no checkboxes or avatars.
- **Type & shape:** custom humanist face ("Superhuman Adelle", Adelle Sans modified over six months for reading speed); sizes 12–14 px; letter-spacing .005em; radii 2–4 px; OpenType kerning/ligatures/smart quotes.
- **Themes:** Snow (light) / Carbon (dark). Carbon rules: no pure black/white; five greys (lighter = nearer); white text at 90 % (65 % secondary); accents darkened + saturated. Twelve account colours. Full-bleed curated photo + hidden chrome at Inbox Zero.
- **Motion:** sparse by doctrine. 150 ms ease opacity/colour fades dominate; 100 ms box-shadow; 200 ms transforms on cubic-bezier(.19,1,.22,1); `.15s` keystroke-shake on rejected keys.
- **Speed doctrine:** every interaction < 100 ms, target < 50 ms (1–2 frames); "measure everything you want to make fast"; local index; preload/prerender likely-next threads; keystrokes pipelined (fast double `C` never makes two drafts); search 3 s → 30 ms.
- **Keyboard (v8 sheet):** Cmd+K command palette (fuzzy, alias-aware, shortcut shown beside each command — "learn as you go"; open-source matcher `command-score`, MIT); `/` search; Z undo (10 s unsend, not extendable); X select, Shift+J/K extend; E done, Shift+E undo done; H remind; S star; U read/unread; `#` trash; `!` spam; L label, Y remove label, `[`/`]` remove-label-and-advance; V move; J/K, N/P, Enter, O expand; G then I/O/S/D/T/E/H/M/!/#/A/L go-to; C/R/Enter(reply-all)/F; Cmd+Enter send; Cmd+Shift+Enter send & done; Cmd+Shift+L send later; `;` snippet; Cmd+J write with AI.
- **Auto-Advance:** after Done/Remind/Trash land on the next conversation (Down/Up/Back-to-list configurable) — "+15 % throughput".
- **Semantics:** E = "Done" (archive renamed; threads return on reply; `#` is the only delete). Counts are totals, not unread.
- **Teaching:** every hover shows the shortcut; Cmd+K lists shortcuts; first-run tutorial keyed to real actions; contextual nudges; guides < 15 min.
- **Criticisms to invert:** price, Gmail/Outlook lock-in, tracking-pixel scandal (→ tracking off by default, image gate), no unified inbox, weak search, US-QWERTY-only shortcuts, no shortcut customisation.
- **Other clients — one idea each:** HEY Screener (accept/deny per first-time sender → fixed streams); Notion Mail views (saved filter+group queries); Shortwave (starred/todos pinned & hand-ordered, bundles); Fastmail (Folders-or-Labels mode over one model); Proton (blocked-tracker badge, dark restyle with "Revert to original"); Front (collision detection + in-thread comments); Spark (Home digest); Mimestream (profiles + opt-in unified view).

## 2. Gmail — what "Gmail-like" concretely means

- **Frame:** top bar (menu, logo, centred pill search ≈48 px tall, help/settings/apps/avatar); search chips row after a query (From · Any time · Has attachment · To · Is unread · Excludes …) + advanced panel (From/To/Subject/Has the words/Doesn't have/Size/Date within/Search in/Has attachment) with *Create filter*; left nav ≈256 px collapsible to icon rail (Compose button, Inbox count, Starred, Snoozed, Sent, Drafts, More…, Labels with colour dots, nesting, hover ⋮ menu: colour/show/hide/edit/remove); right side panel (Calendar/Keep/Tasks/Contacts); Quick-settings panel (live preview: density, theme, inbox type, reading pane, conversation view).
- **Rows:** checkbox · star · importance marker · sender(s) bold-when-unread with "(3)" count · subject – snippet · inline label chips · attachment chips (Default density only) · date. Date rules: today → time; this year → "Sep 1"; older → "9/1/25". Hover replaces the date with archive/delete/mark-read/snooze. Right-click menu with all actions.
- **Selection toolbar** replaces tabs when ≥1 selected: select-all ▾, archive, spam, delete, read/unread, snooze, add to tasks, move to, labels, more (mute, forward as attachment, filter messages like these).
- **Inbox types:** Default (category tabs Primary/Social/Promotions/Updates/Forums), Important first, Unread first, Starred first, Priority, Multiple inboxes. Paging "1–50 of N" with Oldest/Newest jump; page size 50 default, 100 max.
- **Density:** Default (with chips) / Comfortable / Compact (≈40 / 40 / 28–32 px, UNVERIFIED). **Reading pane:** No split / Right of inbox / Below inbox; toolbar toggle; mark-read delay Immediately/1 s/3 s (default)/20 s/Never.
- **Conversation view:** newest at bottom; collapsed one-line cards; `;`/`:` expand/collapse all; trimmed quotes behind "⋯"; attachment chips with preview; inline Reply/Reply all/Forward; Smart Reply chips slot.
- **Compose:** bottom-right popup (≈510×520, UNVERIFIED) with minimize / full-screen / pop-out (Shift-click) / close; To with Cc/Bcc links, avatar chips, autocomplete, external-recipient warning; bottom toolbar Send + ▾ schedule, formatting "A", attach, link (Cmd+K), emoji, …, more (plain text, templates); autosave; Undo Send snackbar 5/10/20/30 s; multiple windows tile.
- **Shortcuts (`?` overlay groups):** Actions: `,` `x` `s` `e` `m` `!` `#` `r` `a` `f` `Shift+n` `]` `[` `z` `Shift+i` `Shift+u` `_` `+`/`=` `-` `b` `;` `:` `Shift+t`. Jumping: `g i/s/b/t/d/a/k/l`. Threadlist: `* a/n/r/u/s/t`. Navigation: `g n/p` `u` `k` `j` `o`/Enter `` ` `` `~`. Application: `c` `d` `/` `q` `.` `v` `l` `?`. Compose: `Cmd+Enter` send, `Cmd+Shift+c/b/f`, `Cmd+k` link. Formatting: `Cmd+b/i/u`, `Cmd+Shift+7/8/9`, `Cmd+[`/`]`, `Cmd+\`.
- **Micro-interactions:** undo snackbar for send and destructive actions (`z`); hover elevation; drag-drop onto labels; auto-advance (Settings ▸ Advanced); nudges; snooze presets (Later today / Tomorrow / This weekend / Next week / Pick).
- **Criticisms to avoid:** clutter and feature creep, category-tab misfiling, ad rows, conversation view burying attachments, labels-vs-folders confusion, settings sprawl, slow loads.
- **Non-negotiables list (10):** three-region frame with central search + chips; full j/k/x/e/#/r/a/f/c/`/` set with `?`, `g`-jumps, `*`-selection, `z`; dense single-line rows with hover actions; selection toolbar + "1–50 of N" paging; 3 densities × 3 reading-pane modes with mark-read delay; threaded cards newest-at-bottom with trimmed quotes and inline reply; bottom-right compose with Cc/Bcc chips, Send+schedule, autosave; undo snackbar; labels not folders (+ Starred/Snoozed/Important views); inbox types + quick settings with live preview + dark mode.

## 3. ihasmail (AGPL) — portable specifics (attribute on port)

- **Shell metrics:** `--topbar-h 56px`, `--sidebar-w 256px` / `68px` collapsed; reading pane `right | bottom | off`, `.pane-right { grid-template-columns: var(--list-size,520px) auto 1fr }`, splitter persisted (`listPaneWidth 520`, `listPaneHeight 340`, min 320/160, double-click reset). Breakpoints: ≤1100 `--list-w 44%`; ≤900 single pane; ≤768 drawer `min(300px,85vw)`, bottom tab bar 60 px + safe-area, full-screen composer `100dvh`. Touch features keyed on `(pointer: coarse)`.
- **Row heights by density:** one-line compact 36 / default 44 / comfortable 52; two-line 56 / 66 / 78. Hover actions *replace the date*. Focused row `inset 3px 0 0 var(--accent)`. Unread bg white vs read `#f3f5f7`, bold from/subject/date.
- **Tokens (light):** `--fs 14px; --radius 10px; --radius-sm 6px; --radius-lg 16px; --shadow-1 0 1px 2px rgba(0,0,0,.06),0 1px 3px rgba(0,0,0,.08); --shadow-2 0 4px 16px rgba(0,0,0,.12),0 2px 6px rgba(0,0,0,.08); --ease cubic-bezier(.2,0,0,1); --bg #f6f8fa; --bg-elev #fff; --border #e3e7ec; --fg #111827; --fg-muted #5b6472; --fg-faint #8b94a3; --accent #0f766e; --star #f59e0b; --focus-ring 0 0 0 3px rgba(15,118,110,.35)`. Dark: `--bg #0b1220 --bg-elev #111a2b --fg #e5e9f0 --border #1f2a3d`. `data-theme|density|accent|fontsize` on `<html>`.
- **Keyboard engine:** scope stack (last pushed wins), two-key sequences with 1200 ms prefix timeout, disabled while a dialog/popover is open, ignored in inputs unless allowed. Map: global `c ? g-i g-s g-t g-d g-a g-l g-c g-f g-k`; mail `j k ↓ ↑ o Enter u Esc x e y # Delete ! s Shift+i Shift+u v l *a Cmd+a r a f n p ]`; composer `Cmd+Enter Esc Cmd+s Ctrl+k Tab`. **No command palette.**
- **Thread view:** expanded = unread-when-opened ∪ last ∪ single; `wasUnread` snapshot so auto-mark-read doesn't collapse under you; `markReadDelay` (default 0, −1 never); opens scrolled to first unread and holds alignment 2 s. Quote selectors: `.gmail_quote, blockquote[type=cite], .moz-cite-prefix, #divRplyFwdMsg, .yahoo_quoted, div[id^=appendonsend], .ms-outlook-mobile-reference-message, #OLK_SRC_BODY_SECTION, .protonmail_quote` + fallback blockquote preceded by `/wrote:\s*$|Original Message|Von:|De :|From:/i` or a lone > 200-char blockquote; `•••` pill.
- **HTML sanitizer (DOMPurify):** FORBID_TAGS `script iframe frame frameset object embed applet form input button textarea select option meta link base svg math video audio source track canvas template slot dialog noscript`; FORBID_ATTR `srcdoc formaction action ping autofocus autoplay contenteditable draggable tabindex`; ADD_TAGS `style center font marquee`; ADD_ATTR `bgcolor background valign align border cellpadding cellspacing width height color face size target`; `<style>` loses `@import`; links get `target=_blank rel=noopener noreferrer nofollow`; CSS hardening `:host → :not(*)`, `position:fixed|sticky → static`; `srcset` dropped; `cid:` → blob; remote `http(s)` counted then blanked/passed/proxied; `<body bgcolor/style>` lifted onto wrapper; shadow root + `contain: layout` on the ancestor as the real containment.
- **Remote images:** policy `ask | always | contacts`, per-sender allow list, click a blocked placeholder to load; count computed but not shown (do show it). Dark: `themeMessageBody` off by default; `htmlDeclaresColors()` keeps self-coloured mail on a white card.
- **Compose dock:** 580×600 fixed bottom-right, minimized 280×44, maximized `inset:24px`, multiple drafts side by side; autosave 20 s after last edit ("Saved 2 minutes ago"); recipients chips (`, ; Enter Tab` commit, Backspace re-edits), suggestions debounced 120 ms max 8 ranked prefix→word→substring; XHR upload with progress; forgot-attachment regex; undo send default 8 s (0–30) with progress toast; FUTURERELEASE scheduled send.
- **Search grammar:** `from to cc subject body has:(attachment|star|flag) is:(unread|read|starred|flagged) in|folder label|keyword (-label:) before after|since newer|newer_than older|older_than larger|size smaller`; dates `YYYY-MM-DD`, `YYYY/MM/DD`, `M/D/YYYY`, relative `Nd|Nw|Nm|Ny`; sizes `k/m/g`. Mapping: text→`text`; has:attachment→`hasAttachment`; is:unread→`notKeyword $seen`; before/after→ISO; larger→`minSize`; in→`inMailbox` via role/alias/name; starred→`hasKeyword $flagged`; labels→`hasKeyword`/`notKeyword`.
- **Live updates:** SSE with 1 s→60 s backoff, reconnect on visibility/online; changes coalesced 400 ms; 120 s poll fallback; full-window refetch (no `queryChanges`); `(N)` title + favicon badge; connection dot.
- **Weaknesses to beat:** hover-only checkbox/actions, non-focusable rows, missing aria-labels, Inter declared but never loaded, `execCommand` editor, full refetch per push, no palette, remote count hidden.

## 4. Implementation techniques (verified versions, 2026-09-02)

- **Morphing:** idiomorph 0.7.4 (`idiomorph-ext.min.js`, 0BSD, 3.4 KB gz): `hx-ext="morph"`, `hx-swap="morph:innerHTML"` on the list, rows keep identity by id; `restoreFocus` on. `im-preserve` is head-only — use `beforeNodeMorphed` to skip islands (`data-morph-ignore`). Keep `x-data` strings static. `hx-preserve` only as last resort. View transitions: opt-in per navigation only (`transition:true`), never global.
- **Prefetch:** htmx-ext-preload 2.1.2 (`preload` = mousedown, `preload="mouseover"` = 100 ms delay); GET-only, browser-cache based → partials need `Cache-Control: private, max-age=60` + `Vary: HX-Request`; preloads send `HX-Preloaded: true` → never mark-read on GET.
- **Optimistic UI:** Alpine mutates first, `hx-swap="none"`, server 204 or `HX-Trigger`; correction via `HX-Retarget` + `HX-Reswap: morph:outerHTML`; one `htmx:afterRequest` (`detail.failed`) reverts. **Undo = immediate commit + reverse op** (JMAP is truth; other devices converge); delayed commit only for send (and permanent delete).
- **Keyboard:** one registry `[{id, keys:['g','i'], group, label, run}]` driving both dispatch and the `?` overlay; `pending` key + 1000 ms timeout; suppress in inputs/contenteditable/`isComposing`; `x-on:keydown.window`. Roving selection keeps `selectedId` in `Alpine.store`, re-read `[data-id]` after `htmx:afterSettle`, fallback to nearest index. Palette: fuzzysort 4.0.2 (MIT, 7.4 KB) or Superhuman's `command-score` (MIT, ~1 KB).
- **Compose lifecycle:** Alpine's MutationObserver auto-inits swapped `x-data` (no `htmx:load` glue — double-init otherwise); `Alpine.data('compose')` with `init()` creating Squire and `destroy()` calling `editor.destroy()`; keep the editor in a closure, not on `this`. Squire needs a paste sanitizer → vendor DOMPurify 3.4.14 (`sanitizeToDOMFragment`). Compose dock is a sibling of the list target, `hx-history="false"`, excluded from morph. Autosave: `hx-trigger="input delay:2s" hx-swap="none" hx-sync="this:replace"`; JMAP bodies immutable → each save = `Email/set` create + destroy old. Attachments via XHR (progress) to a FastAPI route streaming to Stalwart's `uploadUrl`.
- **Lists:** `hx-trigger="intersect once root:#list"` sentinel (not `revealed`); no virtualization — page 50, cap live list, `content-visibility:auto; contain-intrinsic-size:auto 72px` past a few hundred rows; `hx-swap="morph:innerHTML show:none"` keeps scroll.
- **Safe HTML:** nh3 0.3.7 (ammonia 4.1.4): `filter_style_properties` allow-lists property *names* only → add `attribute_filter` regex on `style` blocking `url\(|image-set\(|expression\(|behavior:|-moz-binding|@import|position:(fixed|sticky)|\\[0-9a-f]`; `url_schemes {http,https,mailto,cid,data}` (data only for img+image/); `url_relative="deny"`; never allow `background/srcset/poster`. `<style>` blocks: extract, parse with tinycss2 1.5.1 (drop `@import`/`@font-face`, same allowlist per declaration, escape `</style`), re-emit. Render at a **separate URL with CSP header** (mox recipe): `Content-Security-Policy: sandbox allow-popups allow-popups-to-escape-sandbox; frame-ancestors 'self'; default-src 'none'; img-src data:; style-src 'unsafe-inline'; script-src 'sha256-<resize-script>'` + `Referrer-Policy: no-referrer`; parent `<iframe sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox" referrerpolicy="no-referrer">`; auto-height via the hash-allowed ~15-line ResizeObserver → `parent.postMessage`, parent checks `event.source === iframe.contentWindow && event.origin === 'null'`, clamp 200–20000 px. Two renders `?remote=0|1`. `cid:` → `/msg/{id}/cid/{cid}` with signed token (cookie behaviour UNVERIFIED) or inline small parts as data:. Dark: `?theme=dark` — honour `<meta name=color-scheme>`; else luminance-check + `filter: invert(1) hue-rotate(180deg)` with images re-inverted; per-message revert remembered per sender. Print via `/msg/{id}/print`.
- **Design system:** Tailwind 4.3.3 CSS-first: plain CSS vars carry the theme (`:root`, `:root[data-theme=dark]`, `@media (prefers-color-scheme:dark) :root:not([data-theme=light])`), `@theme inline` maps them to utilities. Density via `--row-h`/`--pad-y` per `[data-density]` — **not** by rescaling `--spacing`. Font: self-hosted Inter 4.1 variable latin `wght` subset (48 KB woff2, OFL 1.1) with metric fallback (`size-adjust 107.47%; ascent-override 90.14%; descent-override 22.44%`), `font-display: swap`, preload. Icons: Lucide 1.39 (ISC) via a Jinja `icon()` macro inlining SVG. Motion: `--default-transition-duration 120ms`, easing `cubic-bezier(.2,0,0,1)`; hover 100–150 ms, panels 200–250 ms; reduced-motion zeroes durations. `:focus-visible` 2 px accent outline.
- **A11y:** list as `role="grid" aria-multiselectable` › `role="row" aria-selected` (+ `aria-current` for the open thread) › `gridcell`; roving tabindex (not `aria-activedescendant`); permanent `role="status" aria-live="polite"` region swapped *into* via `hx-swap-oob="innerHTML:#status"`; native `<dialog>.showModal()` for modals; `@alpinejs/focus` optional; AA contrast per theme.
- **Performance:** Caddy 2.11 (h1/h2/h3, `encode zstd gzip`; brotli only for precompressed static via `file_server precompressed`); Makefile content-hash filenames + manifest + `immutable` caching; one batched JMAP POST per page (RFC 8621 §4.10 chain); Stalwart `maxMethodCalls 16`; SSE `id:` carries JMAP state, replay via `Email/changes`; reconnect banner on `htmx:sseError`; targets partial TTFB < 200 ms, swap paint < 100 ms, INP < 200 ms.
- **Auth:** DB-backed sessions (`secrets.token_urlsafe(32)`, `__Host-sid; Secure; HttpOnly; SameSite=Lax`), id regenerated at login, idle + absolute timeouts, Fernet-encrypted per-user Stalwart credential in the row (revocation point); verify password by fetching the JMAP session with basic auth and checking `username` (Stalwart returns 200 anonymous sessions!); mint per-user `x:ApiKey` via admin (spike SPK-3) rather than storing passwords; CSRF = `__Host-` cookie + per-session token in `<meta>` → inherited `hx-headers` + `Sec-Fetch-Site` check (`HX-Request` alone is not sufficient); rate-limit per IP + account in Postgres *before* calling Stalwart (Stalwart auto-bans after 100 failures/day per source IP — the webmail host would ban itself); `401 + HX-Redirect: /login?next=`; passkeys later via py_webauthn 3.0.
