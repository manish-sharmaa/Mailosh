Mailosh · Phase 1A · visual polish

Polish v2 — depth, contrast, motion

Same frame, same Graphite & Blue identity, same Comfortable 52 px rows. What changes: a real surface ladder, interactive glyphs that all clear WCAG 2.2 AA non-text contrast (3:1) in both themes, circular hover washes on every icon button, a primary action with genuine elevation, and 120–200 ms transitions on colour, background and shadow. Every number on this page is measured, not estimated. Implementation contract: docs/design/polish-v2-spec.md.

1 · the headline fix

Icon buttons — before and after

Today .btn-icon:hover paints background: var(--hover) — the exact colour the hovered row is already painted. The hover state is therefore a 0 px, 1.000:1 no-op: rest and hover are pixel-identical. And transition-property is declared with no transition-duration, whose CSS initial value is 0s, so nothing animates either. The fix: an alpha wash (--ctl-hover) that lifts off whatever is underneath, a circular target, and a glyph that steps from --icon to --icon-strong.

3 · dark

The polished inbox — dark, Comfortable

Carbon rules: no pure black, lighter = nearer. Shadows alone are invisible on a #0D1015 ground — today's Compose shadow uses rgba(15,23,42,.18), whose colour is lighter in luminance (0.0088) than the page it sits on (0.0065), so it renders as a faint halo, not a shadow. Here every dark elevation is a black shadow plus a lighter surface value.

5 · elevation

Three shadow tokens, used deliberately

Resting cards are flat with a hairline. --shadow-1 is the hover lift on a row. --shadow-2 is a menu or a docked compose. --shadow-3 is a genuinely floating layer — toast, palette, modal. In dark, each is a black shadow and a lighter surface, because a shadow on a near-black ground carries almost no information on its own.

6 · motion

Motion — colour, background, shadow. Nothing else.

No transforms on hover, no decorative animation, one easing family. Everything below is zeroed by @media (prefers-reduced-motion: reduce), which the base layer already does.
