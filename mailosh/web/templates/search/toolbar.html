{# The results toolbar — `list/toolbar.html` with search's own addresses. It is a separate file for exactly one reason: every URL in the list's toolbar is written into the markup as `/mail/{key}/…`, and a search has no mailbox key. Everything else is deliberately identical — the same 44px bar, the same tri-state `data-role="select-all"`, the same `data-role="refresh"` hook app.js's endless-scroll bookkeeping looks for, the same `list/range.html` include, the same `aria-disabled` pager ends, and the same selection bar (`list/toolbar_selected.html`) swapped in by the same Alpine `x-show` reading the same store. A selection made in a search behaves like a selection made in the Inbox because it *is* the same one. The bare `x-data` is load-bearing here for the same reason it is there: Alpine only initializes trees rooted at `[x-data]`/`[x-init]`, so a standalone `x-show` is never evaluated at all — silently, leaving the cloaked selection bar invisible forever. #}
