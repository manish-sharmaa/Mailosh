{# The `?` overlay (spec §6.1) — the frame only. Its rows are built by static/js/keys.js from the registry, which is the whole point: the same table that decides what `e` does decides what the overlay says `e` does, so the two can never disagree, and a key that is reserved but not yet implemented (`available: false`) is simply absent here rather than advertised and broken. A native `` opened with `showModal()`, like the bulk confirmation actions.js builds: the focus trap, the backdrop, the inert background and `Esc` are all the platform's, and none of them needs markup, script or an Alpine directive. Rendered once, by layouts/app.html, *outside* `#main` — every htmx swap in this app targets `#main` or `#list`, so the dialog (and the listeners keys.js binds to it) survives every navigation instead of being rebuilt and re-bound on each one. layouts/fragment.html deliberately does not include it: a fragment that carried a second `` would put two of them in the document, and `getElementById` would find whichever came first. #}
