{# The ⌘K command palette (spec §6.2) — the frame only. Every result row is built by static/js/palette.js from `GET /palette/index`, for two reasons that are both about safety rather than taste: a mailbox name is user data, and building rows with `createElement`/`textContent` means no label is ever parsed as markup; and the list is context-aware (the six mutations only appear when there is a selection or an open conversation to run them against), which the server that renders this shell has no way to know. A native `` opened with `showModal()`, like the `?` overlay and the bulk confirmation: the focus trap, the backdrop, the inert background and `Esc` are the platform's, and none of them needs markup, script or an Alpine directive. No `x-data` here for the same reason — there is no Alpine directive on this subtree at all, so there is no `x-show`/`x-bind` to be silently skipped for want of a root. Rendered once, by layouts/app.html, *outside* `#main`: every htmx swap in this app targets `#main` or `#list`, so the dialog and the listeners palette.js binds to it survive every navigation. layouts/fragment.html deliberately does not include it — a swap carrying a second `` would put two in the document and `querySelector` would find whichever came first. #}
