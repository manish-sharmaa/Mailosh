Neither decision is re-made here; this file draws what that list contains. --------------------------------------------------------------------- Two real controls, not one hover affordance Download and Open are `` elements that are in the tab order at all times. `.chip-actions` fades them in on `:hover` AND on `:focus-within` (styles/input.css), which is the whole reason the reveal is `opacity` rather than `display: none` — a control removed from the box tree cannot be focused, so it could never bring itself into view, and spec §11 is explicit that a hover action has to be keyboard-operable. 1A fixed exactly this bug on list rows.
