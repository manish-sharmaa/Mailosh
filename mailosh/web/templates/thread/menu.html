{# The per-message ⋮ menu (spec §7), rendered per message. **Reply, reply all and forward are *this message's*.** The conversation bar's three buttons carry the same `data-compose-reply` and reach `compose.js`'s `reply(mode)`, which replies to the card holding focus or, failing that, to the newest message. A menu item sits inside its own card, but a pointer click does not focus a button on every platform, so "the card holding focus" is not a promise this menu can rely on. `data-compose-email` names the message outright, and static/js/actions.js's capture listener turns that name into the focus `compose.js` reads — before compose's own handler runs — so the reply quotes the message the menu was opened on, whichever card was last touched.
